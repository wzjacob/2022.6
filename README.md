# ARM64 应用大全

面向 **Linux aarch64 / arm64** 的精选应用目录站点。

## 打开页面

```bash
xdg-open linux-arm64-apps/index.html
# 或
cd linux-arm64-apps && npx --yes serve .
```

目录内含分类筛选、搜索，以及官方 / 社区 / 实验支持标注。详见 [`linux-arm64-apps/README.md`](linux-arm64-apps/README.md)。
