# 汇报时钟 · Report Clock

会议汇报用倒计时。受 [Yasumi-Clock](https://github.com/MrXnneHang/Yasumi-Clock) 启发：时间到会全屏强提示，而不是温柔叮一声。

## 快速开始

用浏览器打开：

```bash
open report-clock/index.html
```

或本地起静态服务：

```bash
npx --yes serve report-clock
```

详细说明见 [report-clock/README.md](./report-clock/README.md)。

### 快捷键

- `Space` 开始/暂停 · `N` 下一位 · `R` 重置 · `F` 全屏 · `Esc` 关掉到时提示
