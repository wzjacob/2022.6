# 这是什么

同仁堂官网上的中成药，做成了两个能点的网页。

官网同一味药会挂很多规格（安宫牛黄丸就有十几种写法）。这边先合成 **442 个品种**，再让你按药看、按规格看图。

数据来自 [同仁堂中成药目录](https://www.tongrentang.com/jtProductList/d502e93816624e6780a8e959701ec3af/1.html)，只做展示，不能当医嘱。

## 两个页

- **名方画廊**：上面一排名方，鼠标放上去卡片会拉开。下面是全部药品，点进去能看主治；点某个规格，左边图会换成那一盒的包装。
- **药丸柜**：本来作品集网站用一堆白胶囊当标签。这里改成药丸——中间一颗蜡壳会裂开，下面 442 粒药按剂型上色。点金色的是大蜜丸，点红的是蜡壳货。右上角可切黑底 / 白纸。

顶栏「名方 / 药丸」来回切就行。

## 怎么打开

```bash
cd gallery
pnpm install
pnpm dev
```

浏览器进 http://127.0.0.1:5173/  
药丸柜加个 `#wan`：http://127.0.0.1:5173/#wan
