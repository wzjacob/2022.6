# 为什么做这个

同仁堂官网把中成药按 **货号** 一条条挂出来：同一味安宫牛黄丸能出现十几次，规格写法还不统一。人想找的是「这味药是什么、长什么样、有几种盒」，不是一张说明书清单。

所以这不是又一个爬虫页面，是把公开目录收成 **可以讲品牌、可以比规格、可以认包装** 的陈列。

数据来自 [同仁堂中成药目录](https://www.tongrentang.com/jtProductList/d502e93816624e6780a8e959701ec3af/1.html)。只做展示，不能当医嘱。

## 解决什么麻烦

- **看不清品种**：733 条货号先合成 442 个品。安宫、六味、乌鸡白凤这些名方放最前，其余按药找，不再在重复条目里翻。
- **看不清盒**：官网图长短不一，还常被裁掉字。这里统一垫在 4:5 色板上，盒面文字在，点某个规格就换那一盒的图。
- **看不清剂型**：大蜜丸、水蜜丸、浓缩丸本来是药的身体。药丸柜用公司那种白胶囊标签陈列，左边圆点区分剂型。

## 两个入口，两套价值

**名方画廊**（货架）  
给「我要认药、比盒、看说明书」的人。悬停拉开名方，网格扫完全目录；详情里主治在上、规格在下，点规格图跟着变。

**药丸柜**（记忆）  
给「我要记住这是同仁堂」的人。黑底、方头像、一堆白胶囊，和公司作品集一个感觉；标签换成品种名，点一粒进那味药。

一个管效率，一个管印象。顶栏可以来回切。
