# 汇报时钟 · Report Clock

受 [Yasumi-Clock](https://github.com/MrXnneHang/Yasumi-Clock)「倒计时结束必须看见」的启发，做了一个适合**会议汇报投屏**的网页倒计时。

到点后会弹出全屏「时间到」提示，并可选播放提示音，避免大家拖堂却没人喊停。

## 功能

- 大字倒计时 + 环形进度，适合第二块屏 / 投影仪
- 预设 3 / 5 / 8 / 10 / 15 分钟，也可自定义
- 汇报队列：按名单依次计时，到点点「下一位」自动切换
- 还剩 1 分钟变色提醒；到点全屏强提示（Esc 关闭）
- 全屏模式；名单本地保存

## 使用

本地直接打开：

```bash
# 用浏览器打开
open report-clock/index.html
# 或
xdg-open report-clock/index.html
```

也可用任意静态服务器：

```bash
npx --yes serve report-clock
```

### 快捷键

| 按键 | 作用 |
|------|------|
| `Space` | 开始 / 暂停 |
| `R` | 重置 |
| `N` | 下一位 |
| `F` | 全屏 |
| `Esc` | 关闭到时提示 |

## 建议用法

1. 会前把汇报名单加进队列，选好每人时长（如 5 分钟）
2. 投屏或放到侧屏，点「全屏」
3. 每人开始时点「开始」；到点后全屏提示，再点「下一位」

灵感来自 Yasumi-Clock：不是温柔叮一声，而是**打断你、让你看见**。
