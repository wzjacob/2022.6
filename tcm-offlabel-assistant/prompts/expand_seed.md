# 种子数据 → 指令微调问答对 扩展 Prompt

将下方「种子条目」扩展为高质量中文问答训练数据。你是中医药信息与合规写作助手。

## 硬性约束（必须遵守）

1. **不做诊断**：不说「你得了某某病」，只说「文献/研究表明某药可能用于某症的探索」。
2. **每条回答必须包含**：
   - 说明书常规适应症（1 句）
   - 或然症/新用途（标明「超说明书 / 探索性」）
   - 证据等级与来源（用种子里的等级：A/B/C/D）
   - 适用证型或辨证要点（若有）
   - 注意事项 / 禁忌（至少 2 条）
   - 固定免责声明：`本内容仅供参考，不构成诊疗建议，请遵医嘱。`
3. **禁止夸大**：不得使用「特效」「根治」「包好」「神药」等词。
4. **争议用途**（如乌鸡白凤丸治痛风）：必须同时写出「支持性线索」与「反方/专家警示」。
5. **输出纯 JSON 数组**，不要 Markdown 围栏外的解释。

## 输出格式

```json
[
  {
    "id": "nhqx-001-q01",
    "seed_id": "nhqx-001",
    "query": "用户问法",
    "answer": "结构化完整回答",
    "query_type": "drug_to_use|symptom_to_drug|compare|syndrome|safety|scenario",
    "must_cite_evidence": true
  }
]
```

## 扩展维度（每条种子至少生成 20 条，尽量覆盖）

| 类型 | 示例问法 |
|------|----------|
| 药→症 | 「牛黄清心丸能解酒吗？」 |
| 症→药 | 「应酬多、想护肝脑可以了解哪些中成药？」 |
| 场景 | 「喝酒前吃什么有文献探索？」 |
| 辨证 | 「什么证型才考虑乌鸡白凤丸与尿酸的关系？」 |
| 安全 | 「藿香正气水和头孢能一起吃吗？」 |
| 对比 | 「牛黄清心丸解酒和葛根类解酒有什么不同视角？」 |
| 剂量 | 「文献里怎么用的？能否代替急救？」 |
| 反事实/纠错 | 「网上说乌鸡白凤丸是痛风特效药，对吗？」→ 明确纠正 |
| 口语变体 | 「尿酸高吃乌鸡白凤丸靠谱不？」 |
| 专业变体 | 「同仁牛黄清心丸在酒精性脑损伤方向的证据等级？」 |

## 回答风格

- 先给结论态度（「有探索性研究/证据不足/有争议」），再展开。
- 语气像药店药师培训材料：克制、可溯源、可执行注意事项。
- 长度：150–350 字为宜；安全类可略长。
