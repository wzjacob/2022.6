# 中成药「或然症 / 另类用法」方向：调研与架构笔记

> 更新日期：2026-08-12  
> 目标：把「说明书之外」的中成药真实用法做成可检索、可溯源、可合规展示的知识产品。

## 1. 方向为何成立

通用大模型只「背说明书」，对研究院探索、老药新用、临床观察类信息覆盖差，容易直接否定。

产品护城河 = **信息差 + 证据分级 + 可溯源**：

| 用户问法 | 通用模型常见回答 | 本知识库应呈现 |
|----------|------------------|----------------|
| 牛黄清心丸能解酒吗？ | 「不能，这是开窍药」 | 同仁堂研究院药效学 + 酒精性脑损伤专利，标注探索性 |
| 乌鸡白凤丸能降尿酸吗？ | 「不能 / 妇科药」或网上「特效」两极 | 研究院探索 + 临床观察 + 人民网等专家警示，并列展示 |

## 2. 内部数据背书核验（公开可查）

### 牛黄清心丸

- 同仁堂研究院：解酒、酒精性脑损伤、轻度认知障碍药效学研究，报道称表现出较好解酒与记忆改善作用。
- 发明专利授权：`药物组合物在制备预防或治疗酒精性脑损伤药物中的应用`（CN202410376379.X）。
- 另有血管性认知障碍动物与机制研究（NLRP3 等通路）。

**结论**：解酒/酒精性脑损伤方向有研究院与专利背书，适合作为 **A 级** 种子。

### 乌鸡白凤丸

- 同仁堂研究院：酒精性肝损伤、非酒精性脂肪肝炎、痛风（高尿酸血症）探索性研究。
- 公开临床：有无症状高尿酸血症小样本观察报道。
- 反方：人民网、地方媒体专家明确「不能治痛风 / 缺少充分依据 / 勿当特效药」。

**结论**：有内部探索价值，但公众争议大，必须 **B 级 + 争议并列**，严禁营销话术。

### 其他试点药

- **六味地黄丸**：糖尿病肾病、阴虚相关慢病辅助报道多；药监局修订不良反应说明书 → 辨证与安全提示要强。
- **逍遥丸**：抑郁、乳腺增生、偏头痛等新用途媒体与临床报道。
- **藿香正气水**：外用止痒等经验用法多；高乙醇、头孢相互作用是合规红线。

## 3. 技术方案参考（公开实践）

1. **中成药循证问答 / ChatCPM 类**：指南+说明书知识库 → RAG → 带引用回答。
2. **药企说明书 RAG**：PDF 解析 → 向量库 → 混合检索（向量+BM25）→ DeepSeek/Qwen 生成 + 章节溯源。
3. **中医助手开源（如 qihuang-wenda）**：体质/方剂数据集 + 稀疏检索 RAG。

对本方向的启示：

- **事实型新用途** → 优先 RAG / 结构化库，而不是一上来全量预训练。
- **微调**只负责语气、辨证结构、拒答与安全话术。
- **强制引用 + 证据等级** 是合规与抗幻觉核心。

## 4. 推荐架构（本仓库 MVP）

```
用户提问
   → 关键词/BM25 检索知识库条目
   → 组装「证据卡片」进 Prompt（或直接模板渲染）
   → 输出：常规适应症 + 或然症 + 证据等级 + 注意 + 免责声明
```

后续可替换为：Chroma/FAISS + 中文 Embedding + vLLM(Qwen2.5) + LoRA。

## 6. 合规红线（产品文案必须内嵌）

1. 永久免责声明。
2. 不做诊断。
3. 证据等级可见：A>B>C>D。
4. 区分 OTC / 处方与剂型差异（尤其藿香正气「水」含醇）。
5. 每条可溯源到 URL 或文献题名。
