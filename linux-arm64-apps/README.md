# ARM64 应用大全

面向 **Linux aarch64 / arm64** 的精选应用目录：开发工具、浏览器、办公、多媒体、容器云原生、语言运行时、数据库、终端与游戏。

## 使用

直接用浏览器打开：

```bash
open linux-arm64-apps/index.html
# 或
xdg-open linux-arm64-apps/index.html
```

本地静态服务：

```bash
cd linux-arm64-apps && npx --yes serve .
```

## 功能

- 分类筛选与关键词搜索
- 标注官方支持 / 社区构建 / 实验可用
- 每条提供简要安装提示与官网链接

## 说明

清单为静态参考，安装前请以各项目官网与发行版仓库为准。欢迎按 `data.js` 中的结构补充条目。
