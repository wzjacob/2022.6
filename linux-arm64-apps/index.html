如何选用

在 ARM64 Linux 上优先官方构建，其次 Flatpak / 发行版仓库，再考虑社区与转译。

  1. 核对架构 确认包名含 arm64 / aarch64，避免误下 amd64。
  2. 优先官方渠道 厂商 .deb/.rpm、官方 tarball，或发行版主仓库。
  3. 桌面应用可试 Flatpak Flathub 对 aarch64 覆盖面广，依赖冲突更少。
  4. 缺原生时再用转译 Box64 等可应急运行 x86_64，但性能与兼容性因应用而异。
